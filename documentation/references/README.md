# References

Reference material downloaded for the Stellar-Forge plan on 6 November 2026. What each item supports is in [Source checks](../Source%20checks.md). Only this README and `scripts/` are tracked in Git; everything else here is copyrighted material kept local, because the repository is public.

| Folder | Contents |
| --- | --- |
| `papers/` | arXiv copies of the 17 papers checked in full; file names give the short citation and arXiv id |
| `papers/text/` | plain-text extracts of those papers (made with `pdftotext`), used for searching |
| `web/` | MIST website pages (grids, home, references) and NASA's Sun fact sheet, as fetched |
| `metadata/` | Crossref records and abstracts for every plan reference (`crossref_and_abstracts.json`) |
| `scripts/` | the lookup, search and recomputation scripts used for the checks |
